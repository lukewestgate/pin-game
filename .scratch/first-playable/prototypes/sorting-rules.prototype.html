Peg Game: sorting rules PROTOTYPE, throw away

A test bench for the sorting rules, with no 3D. The Model is a list of Parts. Each Part holds some Pins and can cover Pins on Parts beneath it. Tap a Pin to remove it. It goes to the open Box of its colour, otherwise to the Buffer. Use it to answer:

  • Do 5 Boxes, Capacity 3 and a Buffer of 7 feel right?
  • Does the seeded "next Box colour" rule ever make a level that can't be won, or that feels unfair?
  • Do the edge cases behave as expected: grey Boxes at the end, several drains from one Box closing, and losing the moment a Pin fills the last Buffer slot?
  • Which colour count and Box count make a level interesting? Should the defaults change?
